# Управление категориями

Подмодуль предоставляет странице управления категориями список, создание, редактирование и удаление. Все операции используют общий query/cache контур родительского `categories`.

## Публичный интерфейс

Родительский модуль реэкспортирует `CategoriesManager({ type, onCategoryUpdated })`. Переключатель типа и обновление аналитики после изменения категории остаются ответственностью страницы.

Схемы форм и отдельные UI формы являются внутренними частями подмодуля. Импортируйте `CategoriesManager` из `@/modules/categories`.
