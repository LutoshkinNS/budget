# Выбор категории

Модуль предоставляет контролируемый выбор категории для формы операции. Он загружает категории выбранного типа в порядке использования, показывает загрузку/ошибку/пустой результат и сообщает родителю ID выбранной категории.

## Публичный интерфейс

```tsx
<CategoryPicker type="expense" value={null} onChange={handleChange} />
```

`type` по умолчанию `expense`; `value` и `onChange` используют ID категории или `null`. Модуль не сохраняет операцию и не зависит от модуля транзакций.
