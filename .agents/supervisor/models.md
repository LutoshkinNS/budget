# Модели команды

Экономный профиль выбран пользователем: сильная модель готовит и проверяет работу, Luna реализует ограниченные задачи по готовому контракту.

| Роль | Модель | Reasoning effort | Источник настройки |
| --- | --- | --- | --- |
| supervisor, основной диалог | `gpt-6.1-sol` | `high` | `.codex/config.toml` |
| spec-writer | `gpt-6.1-sol` | `high` | `.codex/agents/spec-writer.toml` |
| developer | `gpt-6-luna` | `high` | `.codex/agents/developer.toml` |
| tester | `gpt-6.1-sol` | `high` | `.codex/agents/tester.toml` |
| reviewer | `gpt-6.1-sol` | `high` | `.codex/agents/reviewer.toml` |

Фактические параметры считывай из TOML перед запуском и сохраняй в поручении. Основной диалог получает проектное значение по умолчанию; явный выбор в интерфейсе или CLI может его изменить. Изменение файлов не переключает уже работающие потоки. Для обнаружения новых имён ролей начни новую сессию.

Именованная роль использует модель из своего TOML. Если роль ещё недоступна в текущем диалоге, встроенному `worker` передай её инструкции и явно задай `model`/`reasoning_effort` из того же файла. Сохрани замену в state и отчёте. Если среда не позволяет выбрать эти параметры или модель недоступна, сообщи об ограничении до запуска; смену профиля согласуй с пользователем.

Одновременно допускаются три субагента. Завершённые потоки закрывай после получения результата. Дочерние субагенты запускаются только смотрителем. Перед выдачей реализации developer проверяй [готовность задачи](../spec-writer/task-readiness.md); неоднозначную архитектуру возвращай составителю и ревьюеру.

На новой копии проекта восстанови локальные `.codex/agents/` по [инструкции подключения](../README.md#подключение-codex). Объявления содержат модель, уровень рассуждений и указатели; сами инструкции принадлежат `.agents/<role>/`.

Настройки ролей и их приоритет описаны в [документации Codex](https://learn.chatgpt.com/docs/agent-configuration/subagents), назначение моделей — в [каталоге моделей](https://learn.chatgpt.com/docs/models).
