# TanStack Query

Применяй этот скилл при разработке или ревью конфигурации запросов и идентичности данных в кэше React-приложения.

1. Проверь установленную версию TanStack Query и принятые в репозитории соглашения о доступе к данным.
2. Загружай только подходящий раздел:
   - Идентичность запроса, параметры, фабрики ключей, фильтры или выборка записей кэша: [Ключи запросов](references/query-keys.md).
   - Общая конфигурация запроса, вывод типов или композиция параметров: [Настройки запросов](references/query-options.md).
3. Если изменение затрагивает обе темы, прочитай оба раздела. При применении учитывай местные соглашения.
4. Проверь поведение в местах использования: ключ однозначно задаёт загружаемые данные, типы и форма кэша сохраняются.

Примеры в справочниках рассчитаны на TanStack Query v5. Для других версий сверь API перед адаптацией примера.
