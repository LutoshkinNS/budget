# Ключи запросов

Прочитай этот раздел, если определяешь идентичность запроса, состав ключа или выбираешь записи кэша для операции.

Ключ запроса задаёт идентичность данных в кэше и зависимости результата. Используй массив с JSON-сериализуемыми значениями. Включай в ключ изменяемые параметры, определяющие набор или форму данных, и по возможности извлекай параметры запроса из того же ключа. Для infinite query идентичность списка включает его фильтры, а переход между страницами ведёт механизм `pageParam`; курсор страницы не следует автоматически превращать в отдельный ключ запроса. Изменение фильтров меняет ключ; `refetch` повторяет запрос с текущими параметрами.

Располагай сегменты от общего к частному, чтобы префиксом можно было выбрать нужное семейство. Разноси списки, отдельные записи и infinite query по разным веткам: данные имеют несовместимую форму, хотя хранятся в одном кэше. Размещай фабрику ключей рядом с запросами этой функции, если в проекте нет другого соглашения.

```ts
const projectKeys = {
  all: ['projects'] as const,
  lists: () => [...projectKeys.all, 'list'] as const,
  list: (filters: ProjectFilters) => [...projectKeys.lists(), filters] as const,
  detail: (id: string) => [...projectKeys.all, 'detail', id] as const,
  infinite: (filters: ProjectFilters) => [...projectKeys.all, 'infinite', filters] as const,
}
```

Для операции с кэшем выбирай самый узкий префикс, покрывающий нужные записи; для одного ключа включай точное совпадение. Обновляй кэш напрямую, только если его текущая форма известна и её можно корректно изменить. Иначе пометь соответствующее семейство устаревшим. Добавляй в ключ счёт, арендатора, локаль или иную область, если она влияет на результат, согласно модели идентичности и безопасности приложения.

```ts
queryClient.invalidateQueries({ queryKey: projectKeys.lists() })
```

Источник: [Effective React Query Keys](https://tkdodo.eu/blog/effective-react-query-keys). Актуальные API сопоставления и работы с кэшем смотри в официальной документации: [Query Keys](https://tanstack.com/query/v5/docs/framework/react/guides/query-keys) и [QueryClient](https://tanstack.com/query/v5/docs/reference/QueryClient).
