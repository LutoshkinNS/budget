# makeLazy Utility Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create a reusable `makeLazy` factory that wraps `React.lazy` + `Suspense`, and apply it to `ExpensesByDays` to reduce the initial JS bundle size.

**Architecture:** A single utility function `makeLazy` in `common/ui/` accepts a dynamic import factory and an optional named export key, wraps the result in `React.lazy` + `Suspense` with a `<Loader />` fallback, and returns a ready-to-use component. `Main.tsx` uses it instead of a static import.

**Tech Stack:** React 18 (`lazy`, `Suspense`), Vite (automatic chunk splitting on dynamic `import()`), TypeScript.

### Task 1: Create `makeLazy` utility

**Files:**
- Create: `apps/frontend/src/common/ui/makeLazy.tsx`

- [ ] **Step 1: Create the file**

```tsx
import { ComponentType, lazy, Suspense } from "react";

import { Loader } from "./loader/Loader";

export function makeLazy<M, P extends object>(
  factory: () => Promise<M>,
  exportName?: keyof M,
) {
  const Component = lazy(() =>
    factory().then((m) => ({
      default: (exportName ? m[exportName] : m) as ComponentType<P>,
    })),
  );

  return function LazyWrapper(props: P) {
    return (
      <Suspense fallback={<Loader />}>
        <Component {...props} />
      </Suspense>
    );
  };
}
```

### Task 2: Apply `makeLazy` to `ExpensesByDays` in `Main.tsx`

**Files:**
- Modify: `apps/frontend/src/pages/main/Main.tsx`

- [ ] **Step 1: Обновить `Main.tsx`**

Заменить содержимое файла:

```tsx
import { Suspense } from "react";

import { Loader } from "@/common/ui/loader/Loader.tsx";
import { CreateExpense, ExpensesByDays } from "@/modules/expenses";

export function Main() {
  return (
    <>
      <CreateExpense />
      <Suspense fallback={<Loader />}>
        <ExpensesByDays />
      </Suspense>
    </>
  );
}
```

На:

```tsx
import { makeLazy } from "@/common/ui/makeLazy";
import { CreateExpense } from "@/modules/expenses";

const ExpensesByDays = makeLazy(
  () => import("@/modules/expenses/ui/ExpensesByDays"),
  "ExpensesByDays",
);

export function Main() {
  return (
    <>
      <CreateExpense />
      <ExpensesByDays />
    </>
  );
}
```
